# Maison Pure | Village des Cigales | Papillon 10 en 11

Landingspagina voor de twee nieuwbouwwoningen Papillon met dalzicht op Village des Cigales
(Lot-et-Garonne), met 7% netto per jaar, 5 jaar gegarandeerd door Maison Pure.

Twee varianten, identieke tekst, alleen het kleurpalet verschilt (A/B-test op palet):

- `index.html` : Maison Pure-palet (diep groen, zongoud, kalksteen-creme)
- `index-tricolore.html` : tricolore-palet (bistro-navy, Bordeaux-wijnrood, brie-creme)

Lettertypen: Fraunces (koppen) en Manrope (tekst).

In de HTML staan per cijfer bron-comments en `BEWIJS NODIG`-markeringen voor wat nog
geverifieerd of aangeleverd moet worden. Zie ook de onderzoeksdossiers in
`Frankrijk/VDC-landing-onderzoek/`.
